## 新版本与旧版本的关系
默认进入 `clinical.html`，旧 `index.html` 及悬停/点击修补代码保留为回归入口。新 PRD 明确采用紧凑提示与主动展开的详情卡，并禁止在岛内临床确认，故新临床模式不再沿用旧横向长条的确认收到按钮。

双击 `start-prototype.cmd` 启动临床岛与控制台。`npm run dev:clinical` 启动网页开发和临床模拟源；页面入口为本机 1420 端口的 `/clinical.html`。旧版仅用 `powershell -File scripts/start-prototype.ps1 -Legacy` 或 EXE `--legacy --studio` 进行对照，需先退出另一个模式的单实例进程。

临床模拟源使用本机 17322；旧版使用 17321。原有 17321 进程不属于本会话可管理权限，已保留，没有提权、强制清理或更改安全策略。新服务器不访问临床网络、不安装服务、不开机自启。

## 场景与业务约束
- 个人工具：25 分钟、短时到期演示、暂停、继续、结束。基于截止时间恢复，不按 tick 次数扣减。重要动态到达保留计时并提供具名切换入口。
- 核心来源：病危医嘱、危急值、关注报告、费用协同、交班未结、出院后报告、报告更正/撤回、标本退回。
- 扩展来源：输血协同、药学核对、检查前材料、转运进度、会诊动态、设备维修。全部为来源只读摘要，不开单、不派工、不完成核对。
- 每个对象绑定来源、院区、就诊、业务对象 ID 与源快照修订号；报告正文中的 v1/v2 为来源报告版本，不把六态演示序号解释为正式报告版本。
- 过期版本不覆盖新版本；不同来源/院区/就诊/对象不合并。缓冲上限 20，溢出明确提示，不宣称可靠投递。
- 费用金额仅在模拟 finance 角色下显示；隐私、未登录、锁屏/全屏模拟下移除敏感正文与提示。权限控制是演示，不是医院 SSO。
- 取消个人关注仅压制该对象的普通自动预览，保留来源记录、正式任务与重要状态。关注不等于负责。
- 正在阅读的详情不被新对象替换；新对象进入可见活动入口。悬停不改变外壳尺寸，不自动打开详情；主动展开不因鼠标离开而关闭。

## 来源窗口与安全导航
导航链为：点击来源入口 → 模拟源核对完整对象和修订 → 短期本机会话票据 → 只读来源窗口 → 再次核验对象、权限、修订。错误对象、旧修订、权限变化和票据过期会拒绝展示。打开成功不更新源临床状态，也不写临床接收记录。

来源窗口明确标为“模拟来源边界”，不是 HIS/LIS/PACS 集成。Rust 只接受本机票据，不接收来源负载提供的任意 URL。临床岛不能通过 `send_wire` 执行旧版 ack 或模拟控制台的场景/角色命令。控制台本身是受信的本机演示工具，尚不是生产身份验证边界。

本轮修正了 QA 多窗口的 WebView2 参数不一致问题：新来源窗口和试验台从同一启动配置继承浏览器参数；正常启动无调试参数。Windows WebView2 共用数据目录时要求参数一致，依据 Tauri 官方文档的 `WebviewWindowBuilder::additional_browser_args` 警告。

## UI 与性能策略
数值及颜色来自原 UI 规范唯一 JSON，`npm run tokens:clinical` 生成 `tokens.json`/`tokens.css`；不另设第二份 token。字体倍率在岛的样式作用域重新计算，验证实际 computed font size，不能只把外壳变宽当作字体放大。

待机 180×34、紧凑基线 280×40、详情默认宽 400、首选最大宽 560。详情头部、滚动正文、来源操作区分层。文字 200%/225% 时增宽、增高并滚动，不缩小字体。浏览器预览按实际浏览器视口计算高度预算，不把已经缩小的模拟桌面再取一次 60%。

浏览器采用无超调的尺寸过渡；Windows 原生按 UI 规范允许的安全降级交付：固定有限 canvas、瞬时切换实际轮廓、内容淡入，不逐帧 resize HWND 或更新 HRGN。该模式没有完成原生连续几何形变的第三阶段验收，不能用浏览器形变或 rAF 数据冒充原生形变已通过。原生默认主屏顶边；任务栏在顶端时使用文档允许的工作区顶边。

原生命中仍为实际轮廓加规范的物理像素余量，不是整个 canvas。相同物理矩形/轮廓跳过原生变更；隐藏状态撤掉窗口。减少动态直接到最终状态。无空闲鼠标轮询、全屏模糊或常驻帧率循环。

## 明确不包含
真实临床数据、来源接口契约联调、医院 SSO、真实危急值投递/接收/升级链、持久化审计、跨用户隔离、可靠离线补拉、真正 Windows 锁屏或屏幕共享自动检测、真实全屏应用自动识别、Windows 10 与混合 DPI 热拔插矩阵、签名安装器、NVDA 人工读屏及临床用户理解测试均未作为生产能力交付。锁屏与全屏开关是显式演示控件。来源 30 分钟过期预算仅为模拟状态保护，正式标准由来源系统与院方确定。

该版本可用于原型评审和界面/接口边界验证，不可作为临床告警唯一通道。


## 2026-10-04 · U 型与原生连续形变恢复

此节按用户最新选择替代临床模块的圆弧外耳形状与瞬时几何降级。默认视觉总宽高恢复为 160×34 DIP；7 DIP 耳角收在总宽内部，下方双三次曲线与旧版 U 形一致。保留 400 DIP 基线的临床可滚动详情、200% / 225% 文字适配，未将新业务内容退回旧单行通知。

展开使用旧版 ζ=.84、ω=13 归一化轻弹簧（宽度540ms，高度单调），收回340ms；内容短暂退出、按最终布局进入，不缩放文字、不加全屏模糊。隐私/权限收紧立即删除敏感 DOM，不为淡出保留患者快照。默认悬停仍不自动展开或改变外壳。

原生 HWND 画布在普通转换中保持固定。仅在有限动画期允许单在途、最新帧合并的 HRGN 交接，原生准备前/后相邻轮廓并集后才绘制，最终收敛为真实轮廓；不是将整个画布设为可点击。旧 epoch、帧序号、关闭阶段及卸载均受保护。此为对原“所有逐帧区域 IPC 禁止”的最小例外，绝不允许逐帧 resize HWND 或空闲轮询。

数值与路径唯一权威：`docs/Dynamic-Island-UI-Spec.md` 1.1 的第3/4/9/10章；执行 `npm run tokens:clinical` 生成。当前验证记录目录 `evidence/clinical-motion-20261004/`，不得引用旧的静态路径结果作为本轮动效通过证据。Figma 再次读取被 Starter 额度拒绝，本轮未修改远端画板。
