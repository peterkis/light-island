# 应用、状态与来源边界

修改连接、状态、阅读、原生能力、启动或资源拆分时读取本页及 [程序拆分说明](../APP-SPLIT-20261014.md)。本页是当前约束；该说明保存实现细节和验收记录。

## 所有权

| 对象 | 所有者与边界 |
| --- | --- |
| 桌面岛 | `src/clinical/` 默认入口、`src-tauri/`；个人计时、偏好、展开、静音、撤销、原生窗口和只读来源窗口 |
| 工作台 | `workbench/src-tauri/`、工作台前端；内置 Rust/Tokio/Axum 模拟服务，独立预览控制器、计时和覆盖层 |
| 来源连接 | 仅岛所属来源窗口共享岛的 Rust 连接。预览使用可注入连接；不得恢复模块级共享 sender 或 studio/岛共用连接 |
| 原生能力 | 只有 `island` 窗口同步原生区域。浏览器和工作台预览不调用岛几何、焦点、capture 或阅读时钟命令 |
| 资源与进程 | 两套入口、包、权限、单实例和 WebView 数据目录独立；正常发布不需 Node 或第三个守护进程 |

灵动岛保留 `local.samewave.island.prototype`；工作台为 `local.samewave.workbench.prototype`。重复启动只操作本程序；`--studio` 兼容启动独立工作台。默认 `clinical.html`，`--legacy` 选择历史模块。

## 来源协议与本地状态

- 临床来源默认 `127.0.0.1:17322/events`，legacy 为 17321。工作台关闭即停止监听；岛的个人工具继续运行，来源按有界退避重连。
- v2 先完成兼容版本、来源 session、角色和连接身份握手再在线。重启生成新 session；旧帧、票据、请求、私有回复和迟到结果失效。重连不刷新来源原时间、不重播旧预览。
- 工作台预览固定连接自己的就绪服务及 session；绑定失败保持离线。“启动／连接灵动岛”也先验证本服务正在监听。端口冲突只报告错误。
- 来源快照仅含来源设置和活动。计时截止时间、暂停剩余、展示偏好、展开、静音、撤销和阅读会话归各 viewer；来源重置、重要事件和重连不能改写它们。
- 实验显式选择预览或桌面。普通预览点击始终属于预览；检查实验按钮调用前的 `close`、burn guard、延迟回调等副作用是否也按目标隔离。
- 来源通道仅接受允许的只读请求及相关实验结果；模拟配置、重置在工作台执行。保留消息大小、队列/请求容量、去重、私有路由及慢消费者断开限制，具体数值以 [拆分说明](../APP-SPLIT-20261014.md) 和实现为准。
- 临床来源没有确认收到、完成、派单、财务、处方或治疗写入；`clinical:personal` 只控制个人工具。本地设置和模拟角色不能授予来源权限。
- legacy 的 `received` 不等于 `treated`；成功必须匹配服务端事件 id/revision 回执。危急事件各自可识别，只有普通且无需确认的更新可合并。

## 阅读失效与连接生命周期

- 未知网络/原生数据先解析再入状态；TS 类型、`invoke<T>` 和 `listen<T>` 不提供运行时校验。畸形快照不能被当作权威删除。
- 权威对象删除、版本/身份改变、撤回、权限变化及断连都立即清除报告、详情、票据和待请求；对象找不到也必须执行失效逻辑。仅保留允许的离线摘要。
- 覆盖岛内 alert/sum/read、来源窗口和预览覆盖层。不能用 DOM 隐藏代替引用擦除、预算释放、capture/clock 清理； outgoing 层也不能保留失权内容。
- 回复必须匹配当前对象、版本、session 和请求窗口。未在线不发初次读取；清理后旧回复不能重新恢复报告。
- 阅读时长以单调 `performance.now()` / `ReadBudget` 计算。暂停停止展示 tick，恢复沿原预算；原生时间桥接沿既有契约，不以墙上时间重建寿命。
- 连接支持取消、部分监听失败回滚、generation 隔离和初始化拒绝处理。StrictMode setup/cleanup/setup、卸载和迟到注册都不能泄漏监听或安装旧 sender。
- 仅既有动效枚举可独立持久化；患者/来源对象、报告、阅读历史、计时状态不新增落盘。
