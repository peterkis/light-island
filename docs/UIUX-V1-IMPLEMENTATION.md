## 必须明确的解释与差异

1. §2.2 的宽度按主体宽度解释，Notch 两边各增加 10 DIP 外耳。因此静默视觉外接宽度为 144 DIP，不是旧版 160 DIP。展开中心线始终是主体/显示器中心。
2. §2.2 指定 S4/S5 半径 36/40，与 §2.3 的通用 `min(h/2,44)` 不完全一致。本实现采用明确状态表并按实时高度插值。曲线是公开数值的数学近似，不能宣称获得 Apple 私有参数或 Figma 专有平滑算法的逐像素等价。
3. §9.4 的 90ms 入场表与 §13.1 文字存在歧义，本轮采用明确时间表：外壳先动，90ms 后内容入场，不等弹簧完全静止才显示。
4. 普通文字保持 30% 高度上限；200%/225% 文字为保留操作可达性，最多使用 60%/480 DIP 并将详情滚动。这是 §11.1 不截断要求与 §2.2 高度上限之间的明确优先级，不缩小字体冒充适配。
5. 指针区域不额外扩出不可见 8 DIP 挡板；保留 2 个物理像素抗锯齿余量，优先满足透明区域穿透。触屏 44 DIP 热区全矩阵未验收。
6. 色彩填充按钮部分使用黑字，避免 Blue/Red 填充配白字达不到正文 4.5:1；不改变语义色。阴影采用有限的距离场近似，不宣称与 CSS 在所有 DPI 下逐像素相同。
7. S2 已有独立形体、弹簧分离/合并与切换；粘滞颈部仍未加入。按钮按压有样式反馈，但独立弹簧反馈 hook 未加入。两项新增脚本写入被工具安全检查拦截，未改用别的路径绕过。
8. 新键盘/文字缩放回归文件的整份写入也被工具检查拦截。原有 `clinical-accessibility.spec.ts` 保留，其中旧 15px/单卡片断言已不适用于本规范；不能把该文件算作本轮通过。已有高对比度与焦点检查仍在临床场景回归中执行。
9. SHQueryUserNotificationState 不等于所有屏幕共享软件或 Windows 专注助手接口。真实 OS 锁屏/多屏/125%–200%/120Hz/讲述人/触摸需要单独验收；浏览器 DPR、rAF 和手工切换开关不冒充这些结果。
10. 邮件、媒体、通话、下载、AI 等是通用模板参考，本轮没有新增这些外部系统接入。临床接收/处置/派单仍不可由灵动岛执行；来源按钮继续校验对象与版本后打开本机模拟来源。

## 本轮发现并修复的回归

权限变化且外壳尺寸相同时，弹簧会先于内容退出结束。旧实现清除了延迟入场计时器却没有解除 inert，导致“详情”按钮看得见但点不到。现在内容呈现有独立完成标记，尺寸静止也要完成内容交接，解除 inert；不通过延长延时掩盖。

来源对象切换和重置时，旧 S6 面板归属必须清理。关闭时面板归零不应再次生成内容过渡。稳定 SVG 在内容 inert 期间仍支持用户点击反向打开。

## 最终原生性能修补与验收（2026-10-06T23:59:00.673735+08:00）

检测到 96 次同步 GetPixel 的亮度采样在本机消耗 2.1–3.2 秒，虽 rAF 仍有 60Hz，但阻塞了原生轮廓呈现。现改为一次受限 BitBlt 到临时内存 DIB，GdiFlush 后仅计算平均亮度并释放全部 GDI 资源，不保存桌面图像；动画期间跳过采样。实测调用降至 15.7–22ms。阴影距离计算避免通用 hypot，变形提交下降到约 8.9–12.8ms。

相同采样脚本的未变化动画形体样本由 180/195 降至 27/197；该值包含收回等待及有限 IPC 交接，不是 DWM 掉帧率。最终 rAF 60.00Hz，P95 16.9ms，>25ms 0。真实屏幕 95 张采样均无整体空白，6 次专用背景点击通过，其中包含实际阴影像素区域。

最终：类型检查、172 项 TS 单测、6 项 Rust 测试、48 项适用 E2E、Release 构建通过。旧 accessibility 文件 3 项尺寸断言未迁移，不计通过。实际源码及 EXE 与测试记录哈希一致。正常模式已恢复，9223 关闭。完整结果见 `evidence/uiux-final-20261006/RESULTS.json`。

仍未完成的非核心细节：S2 粘滞颈部、独立按钮弹簧/失败抖动、每来源静音、完整滑走撤销、Compact 跑马灯。隐藏涉及权限/系统安全时立即隐藏，不为装饰动画延迟敏感内容保护。不得把以上部分或未测设备矩阵描述成完美验收。
