# Windows 灵动岛 UI/UX 设计规范 v1.0

*Dynamic Island for Windows · Design Specification*

适用：Windows 10 22H2 / Windows 11　·　单位：DIP（100% 缩放下 1 DIP = 1 px）　·　状态：Draft

## 0. 阅读说明

- **参照对象**：iPhone 灵动岛（Live Activities 的 compact / minimal / expanded 三态语言）+ MacBook Pro 刘海「挂在屏幕顶边」的形态语言。
- **关于数值**：Apple 并未公开全部视觉参数。本文的尺寸、弹簧、时序是依据 HIG 公开信息与动效观察得出的**推荐起始值**，标 ★ 的项必须在目标设备上实机校准。
- **刘海 ≠ 灵动岛**：刘海是硬件缺口，灵动岛是软件形变。Windows 屏幕没有缺口，所以本项目的本质是「模拟一块会形变的黑色硬件」，这决定了下面所有规则。

## 1. 设计原则

| # | 原则 | 落地含义 |
| --- | --- | --- |
| 1 | 物体感 | 岛是同一个物体的形变，不是弹窗；内容不「出现」，只「被容纳」 |
| 2 | 克制 | 纯黑底 + 白字 + 同一时刻最多一个语义色 |
| 3 | 连续 | 任何状态切换都用弹簧形变连接，禁止硬切 |
| 4 | 可打断 | 动画任意时刻可被反向，不排队、不等待 |
| 5 | 一眼读懂 | compact 态 1 秒内读懂；expanded 态不超过 3 个信息层级 |

## 2. 形态与几何

### 2.1 两种停靠模式

| 模式 | 描述 | 适用 |
| --- | --- | --- |
| **A · Notch 贴顶（默认）** | 顶边与屏幕顶边齐平，顶部两侧带向外的凹形「耳朵」，下角圆角；最接近 MacBook 刘海 | 追求 Mac 质感 |
| **B · Floating 悬浮** | 顶部偏移 8 DIP，全圆角胶囊；最接近 iPhone 灵动岛 | 多显示器、顶部有标题栏的软件 |

> 交互红利：A 模式下岛接触屏幕顶边，鼠标「甩到顶」即可命中（屏幕边缘对指针是无限深的目标，费茨定律），因此 A 模式的悬停热区必须延伸到 y=0。

### 2.2 状态与尺寸 ★

| 状态 | 代号 | 宽×高 | 下角圆角 | 说明 |
| --- | --- | --- | --- | --- |
| 静默 | S0 Idle | 124×32 | 16 | 休眠胶囊，可配置为完全隐藏 |
| 紧凑 | S1 Compact | 200–268×36 | 18 | 左槽 + 中央留白 + 右槽，承载 1 个进行中事件 |
| 极简 | S2 Minimal | 36×36 | 18（正圆） | 第二个事件，从 S1 右侧分离 |
| 预览 | Peek | S1 × 1.05 | — | 悬停反馈，非独立状态 |
| 展开·短 | S4 Alert | 372×88 | 36 | 通知抬头（消息、邮件、日历） |
| 展开·中 | S5 Rich | 372×168 | 40 | 媒体、计时、通话、快捷回复 |
| 展开·长 | S6 Stack | 400×（≤280） | 44 | 多事件托盘，超出滚动 |

规则：宽度取 4 的倍数；高度不超过屏幕高度的 30%；展开态相对显示器水平居中，尺寸变化时中心线不动；S1 中央留白 124 保持与 S0 同一黑体重心（Windows 无摄像头，默认留白以保持 Apple 气质，可选填充单行文字）。

### 2.3 曲率

- 全部圆角使用**连续曲率（squircle，Figma 圆角平滑 60%）**，不用标准圆弧圆角——这是「像苹果」最关键的细节。
- 半径随高度联动：r = min(h/2, 44)，形变中圆角实时插值，不单独动画。
- 实现：WinUI / Skia 用超椭圆路径；Web / Tauri 用 `corner-shape: squircle`，以 SVG clip-path 兜底。

### 2.4 SVG：基础形体

Notch 模式（主体宽 220、高 36、耳朵 e=10、下角 r=18，整体宽 240）。耳朵半径恒为 10，展开时不放大：

```
<svg viewBox='0 0 240 36' xmlns='http://www.w3.org/2000/svg'>
  <path fill='#000' d='M0 0H240A10 10 0 0 0 230 10V18A18 18 0 0 1 212 36H28A18 18 0 0 1 10 18V10A10 10 0 0 0 0 0Z'/>
</svg>
```

Floating 模式：

```
<rect width='220' height='36' rx='18' fill='#000'/>
```

### 2.5 命中区

- 指针最小命中区 32×32；触屏 44×44；S0 / S2 用不可见热区向外扩 8 DIP。
- 岛外的透明区域（含阴影边距）必须点击穿透。

## 3. 色彩

### 3.1 原则

岛为**纯暗色**设计，不随系统浅色模式变化——浅色桌面上黑岛反而更像一块硬件。

### 3.2 表面与填充

| Token | 值 | 用途 |
| --- | --- | --- |
| surface.island | #000000 | 岛本体，不透明，禁用模糊 / 亚克力 |
| surface.card | #1C1C1E | 岛内二级卡片（输入框、列表项） |
| surface.card-hover | #2C2C2E | 卡片悬停 |
| fill.control | rgba(255,255,255,0.14) | 圆形 / 胶囊按钮默认 |
| fill.control-hover | rgba(255,255,255,0.20) | 悬停 |
| fill.control-pressed | rgba(255,255,255,0.10) | 按下 |
| stroke.hairline | rgba(255,255,255,0.08) | 自适应描边，见 §6.2 |
| separator | rgba(84,84,88,0.65) | 分割线，1 px |

### 3.3 文字色

| Token | 值 | 对黑底对比度 | 用途 |
| --- | --- | --- | --- |
| text.primary | #FFFFFF | 21:1 | 标题、核心数字 |
| text.secondary | rgba(235,235,245,0.60) | 约 6:1 | 正文、副标题、时间 |
| text.tertiary | rgba(235,235,245,0.30) | 约 2:1 | 仅用于禁用 / 装饰，不承载信息 |

### 3.4 语义色（Apple 暗色系统色）

| 语义 | 色值 | 用于 |
| --- | --- | --- |
| Green | #30D158 | 消息、接听、成功 |
| Blue | #0A84FF | 邮件、下载、链接、发送 |
| Red | #FF453A | 日历、挂断、错误、录制 |
| Orange | #FF9F0A | 计时器、低电量 |
| Yellow | #FFD60A | 警告 |
| Pink | #FF375F | 音乐 |
| Purple | #BF5AF2 | AI / 助手 |
| Teal | #40C8E0 | 蓝牙、连接 |
| Indigo | #5E5CE6 | 专注、勿扰 |
| Gray | #8E8E93 | 离线、次要 |

### 3.5 用色规则

1. 同一时刻岛上最多 **1 个强调色**（红绿成对的接听 / 挂断除外）。
2. 强调色只用于图标底、进度、主按钮、状态点，不用于大面积背景。
3. **氛围光**：S5 及以上可在内容后放置取自应用图标 / 封面主色的径向渐变，不透明度 ≤ 18%，模糊半径 40，圆心偏左上；S4 不使用。
4. 禁止渐变描边 / 彩虹边，仅 AI 思考态例外（§9.6）。
5. 所有信息文字对比度 ≥ 4.5:1，核心信息 ≥ 7:1。

## 4. 字体与排版

### 4.1 字体栈

Apple 的 SF Pro 不允许在 Windows 上分发，使用最接近的替代：

- 西文 / 数字：`Segoe UI Variable Display`（≥ 20）/ `Segoe UI Variable Text`（< 20），兜底 `Inter`、`Segoe UI`；开启光学尺寸 `opsz` 自动。
- 中文：`MiSans` 或 `HarmonyOS Sans SC`（需自行核对商用授权），兜底 `Microsoft YaHei UI`。
- 计时、进度、时间一律开启等宽数字 `tnum`，避免数字跳动。

### 4.2 字阶（DIP，字号 / 行高）

| 角色 | 字号/行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- |
| Hero Number | 34/40 | 600 | -0.4 | 倒计时、大数字 |
| Title-L | 17/22 | 600 | -0.3 | 通话人名、歌名 |
| Title | 15/20 | 600 | -0.2 | 发件人、标题 |
| Body | 13/18 | 400 | 0 | 消息预览、正文 |
| Body-Strong | 13/18 | 600 | 0 | 按钮文字 |
| Caption | 11/14 | 500 | +0.1 | 时间、应用名 |
| Compact | 13/16 | 600 | 0 | S1 内的唯一文字 |

### 4.3 排版规则

- 只用 400 / 500 / 600 三档字重；禁用 ≥ 700 与 ≤ 300。
- 消息预览最多 2 行，末尾省略号；标题 1 行。
- S1 内文字单行；溢出时做横向跑马灯（30 DIP/s，首尾各停顿 1.2 s）。
- 中英混排不额外插入空格，交给字体间距处理；数字一律 tnum。
- 透明分层窗口里 ClearType 不可用，只能灰度抗锯齿；黑底白字视觉偏粗，实机比对后可将 600 微调到约 550（可变字体）★。

## 5. 间距与布局

### 5.1 栅格

- 基础栅格 4 DIP；2 DIP 仅用于图标光学校正。
- 间距 token：xs 4 / s 8 / m 12 / l 16 / xl 20 / xxl 24。

### 5.2 内边距

| 状态 | 水平 | 垂直 | 备注 |
| --- | --- | --- | --- |
| S1 | 12 | 6 | 槽宽 40–72 |
| S4 | 20 | 16 | 头像与文字间距 12 |
| S5 | 20 | 18 | 行间距 12 |
| S6 | 16 | 16 | 列表项间距 8 |

**安全区**：内容必须落在圆角的内接安全区内，距边 ≥ r × 0.3，否则文字看起来会被圆角「啃」掉一块。

### 5.3 布局骨架

```
S1 Compact（H36）
[12][图标24][8] 左槽 ┃ 中央留白 124 ┃ 右槽 [数据][12]

S4 Alert（372×88，上下 16）
[20][头像44][12][ 标题 Title       时间 Caption ][20]
                [ 正文 Body ×2 行                ]

S5 Rich（372×168）
行1 H20  [应用图标20] 应用名 Caption ········ 时间
行2 H52  [封面/头像 52] 标题 Title-L + 副标题 Body
行3 H44  进度条 / 控制按钮 / 输入框
行间距 12
```

## 6. 层次、边框与阴影

### 6.1 层

| 层 | 内容 |
| --- | --- |
| L0 | 岛本体 #000 |
| L1 | 氛围光 |
| L2 | 内容（文字、图标） |
| L3 | 二级卡片 / 控件 |
| L4 | 焦点环、气泡提示 |

岛内只有两个明度层：#000 与 #1C1C1E，不引入第三种灰块，否则层次会「脏」。

### 6.2 边框

- 默认**无边框**（Apple 原则）。
- Windows 适配：岛浮在任意壁纸上，背景很暗时纯黑岛会「融」进去而丢失轮廓。方案：每 2 s 或壁纸变化时采样岛下方 160×60 区域的平均亮度；亮度 < 0.15 时启用 0.5 DIP 内描边 `rgba(255,255,255,0.08)`，上沿高光 0.14；亮度 ≥ 0.15 不描边。A 模式贴顶时不绘制顶边描边。
- 高对比度模式：强制 2 DIP 系统前景色描边。

### 6.3 阴影

- S0 / S1 / S2：无阴影。
- S4 及以上：`0 12 32 -4 rgba(0,0,0,0.45)` + `0 2 6 rgba(0,0,0,0.30)`；展开过程中阴影不透明度随高度同步 0→1。
- 实现：窗口四周预留 48 DIP 透明边距用于绘制阴影，边距区域点击穿透。

## 7. 组件规范

### 7.1 按钮

| 类型 | 尺寸 | 形状 | 填充 | 内容 |
| --- | --- | --- | --- | --- |
| 圆形图标按钮 | 44（S5）/ 36（S4） | 正圆 | fill.control | 图标 20 / 18，白 |
| 胶囊文字按钮 | 高 32，横向 padding 14，最小宽 64 | r=16 | fill.control | Body-Strong，白 |
| 主操作（接听） | 同胶囊 | 同上 | #30D158 | 白 |
| 危险操作（挂断） | 同胶囊 | 同上 | #FF453A | 白 |
| 播放 / 暂停 | 44，无底 | — | 无 | 图标 28，白 |
| 关闭 | 24，热区 32 | 正圆 | fill.control | 图标 12 |

- **无边框**；按钮间距 12；同一行 ≤ 3 个。
- Hover：填充 +6% 白；Pressed：填充 −4% 白，且 scale 0.94（80 ms）；释放用 spring.press 回弹。
- Focus-visible：2 DIP 白色 80% 外环，与按钮间隔 2。Disabled：不透明度 0.35。

### 7.2 图标

- 24×24 网格，线宽 1.75，端点与拐角圆润（round cap / join），内边距 2。
- 两种变体：outline（默认）与 filled（激活 / 选中）；单色 `currentColor`，禁止多色图标（应用图标除外）。
- 尺寸：Compact 14–16；常规 20；按钮 20 / 28；Hero 40。
- 系统语义优先用 Segoe Fluent Icons；品牌与自定义图标按本规范自绘，保持 SF Symbols 式的统一线宽。
- 应用图标为 squircle，圆角 = 边长 × 0.2237：S1 22；S4 44；S5 行1 为 20、主体为 52。
- 头像为正圆：S1 24 / S4 44 / S5 52；无头像时用 #3A3A3C 底 + 姓名首字（Title，白）。

### 7.3 进度条

高 4，圆角 2，轨道 `rgba(255,255,255,0.18)`，填充为白或语义色；拖动时高度以 spring.press 长到 8。两端时间用 Caption + tnum，位于条下方。

### 7.4 快捷回复输入框

高 36，r=18，底色 surface.card，左 padding 14，Body；占位符用 text.secondary；右侧发送按钮为 28 的蓝色正圆（#0A84FF）+ 14 的向上箭头。聚焦时岛由 S4 弹升至 S5；这是**唯一允许抢占键盘焦点**的场景，提交或 Esc 后把焦点归还给之前的窗口。

### 7.5 状态点

8×8 正圆，取语义色；录制红点做呼吸（§9.5）。

## 8. 事件模板

### 8.1 模板总表

| 模板 | S1 左槽 / 右槽 | 展开内容（S4 / S5） | 默认停留 | 优先级 |
| --- | --- | --- | --- | --- |
| 即时消息 | 头像 24 / 未读数徽标 | S4：头像 44 + 发件人 + 预览 2 行 + 时间；S5：加快捷回复输入框 | 5 s，悬停暂停 | P2 |
| 邮件 | 邮件图标（蓝）/ 发件人首字 | 发件人、主题、摘要 1 行；按钮：归档、标为已读 | 5 s | P2 |
| 日历提醒 | 日期图标 / 倒计时 | 标题、时间、地点；按钮：加入、稍后 | 8 s；开始前 1 分钟转为常驻 | P1 |
| 计时 / 番茄钟 | 环形进度 / 剩余时间 | Hero Number + 暂停、停止 | 常驻至结束 | P1 |
| 来电 / 语音 | 头像 / 波形 | 人名 Title-L + 接听（绿）、挂断（红） | 常驻至处理 | P0 |
| 媒体播放 | 封面 22 / 波形 | 封面 52 + 歌名 + 歌手 + 进度条 + 控制 | 切歌后 4 s | P3 |
| 下载 / 传输 | 类型图标 / 环形进度 | 文件名 + 进度条 + 速度 / 剩余时间 | 常驻至完成 | P3 |
| 系统 HUD（电量、蓝牙、USB、音量） | 图标 / 数值 | S4 精简变体：图标 + 进度条 + 数值 | 2 s | P2 |
| 错误 / 警告 | 黄或红图标 / 无 | 标题 + 一句话 + 主操作；不自动消失 | 常驻至处理 | P0–P1 |
| AI 助手 | 紫色光点 / 波形 | 状态文字 + 流式输出，见 §9.6 | 常驻 | P2 |

### 8.2 通用卡片骨架

所有模板共享同一骨架，只替换内容：

- **身份区（左）**：图标 / 头像 / 封面，S4 为 44，S5 主体为 52。
- **主信息区（中）**：第一行 Title 或 Title-L，第二行 Body 或 Caption。
- **操作区**：S4 放右侧（单个圆形按钮或时间），S5 放底行。
- **时间戳**：固定在右上角，Caption，text.secondary。
- S5 高度以 4 为单位随内容在 140–168 之间取值。

### 8.3 内容规则

- 标题 ≤ 24 字，预览 ≤ 60 字，超出省略。
- 每个模板最多 2 个主按钮 + 1 个关闭，主按钮在右。
- 同一会话 3 s 内的多条消息合并为一张卡（计数 +n），不重复弹出。
- 隐私：检测到屏幕共享、演示、锁屏前后，消息预览替换为「新消息」，该开关默认开启。
- 文案克制：句末不加标点，不用感叹号，不用 emoji 做装饰。

### 8.4 重点模板细则

**即时消息（S4，372×88）**

- 头像 44 正圆，距左 20，垂直居中。
- 发件人 Title（白）；时间 Caption（secondary）在同一行右端。
- 预览 Body（secondary），最多 2 行。
- 点击卡片主体：打开对应会话；点击岛外：收起。
- 点击回复入口或长按：升级为 S5，底部出现快捷回复输入框（§7.4）。

**来电（S5）**

- 头像 52，人名 Title-L，状态行 Body（「语音通话」或通话计时，tnum）。
- 底行两个等宽胶囊按钮，各 ≥ 120：左挂断（红）、右接听（绿），间距 12。
- 来电期间 S1 左槽为头像、右槽为波形；不自动收起。

**媒体（S5）**

- 封面 52，r=10；歌名 Title-L 1 行，歌手 Body secondary 1 行。
- 进度条（§7.3）距上方 12；两端时间 Caption + tnum。
- 控制行：上一首 / 播放暂停（28）/ 下一首，水平居中，间距 28。
- 氛围光取封面主色，不透明度 ≤ 18%。
- 切歌：封面 200 ms 交叉淡化，文字上滑 6 并淡入。

**计时（S4 变体）**

- 左侧环形进度 44，中部 Hero Number（tnum），右端暂停 / 停止。
- 结束：数字闪烁 2 次（opacity 1↔0.3，每次 300 ms），随后按 P1 常驻提醒。

**系统 HUD（280×56）**

- 左图标 20，中进度条（高 6，r=3），右数值 Caption。
- 滚轮或滑动可实时调整；松手 1.2 s 后收起。

## 9. 动效

### 9.1 总则

- 一切形变由**弹簧**驱动，不用固定时长的线性 / 缓动曲线（内容淡入淡出除外）。
- 只动画 transform（位移、缩放）、opacity、clip-path / 路径；容器宽高由自绘形体插值完成，内容层锚定在顶边中心，不参与布局重排。
- 目标 120 / 60 fps；120 Hz 下单帧预算 ≤ 8 ms；使用 GPU 合成。
- 动画必须**可打断并继承速度**：中途反向时从当前位置和速度继续，不重置。

### 9.2 弹簧 token（质量 m=1）★

| Token | 用途 | stiffness k | damping c | 约等于（response / ζ） |
| --- | --- | --- | --- | --- |
| spring.expand | 展开 | 190 | 22 | 0.46 s / 0.80 |
| spring.collapse | 收起 | 260 | 28 | 0.39 s / 0.87 |
| spring.morph | S0 ↔ S1、S2 分离 | 320 | 26 | 0.35 s / 0.73 |
| spring.press | 按钮、徽标回弹 | 400 | 24 | 0.31 s / 0.60 |
| spring.peek | 悬停放大 | 300 | 30 | 0.36 s / 0.87 |

换算：k = (2π / response)²，c = 4π·ζ / response。过冲预算：展开 ≤ 6%（要有「弹」感），收起 ≤ 2%，悬停 ≤ 1%。

### 9.3 缓动与时长 token

| Token | 值 | 用途 |
| --- | --- | --- |
| ease.out | cubic-bezier(0.2, 0.8, 0.2, 1) | 内容出现 |
| ease.in | cubic-bezier(0.4, 0, 1, 1) | 内容消失 |
| ease.inout | cubic-bezier(0.65, 0, 0.35, 1) | 循环动画 |
| dur.fast | 120 ms | 内容淡出、按下反馈 |
| dur.base | 200 ms | 阴影、数字滚动 |
| dur.slow | 320 ms | 内容入场 |

### 9.4 编排

**展开（S0 / S1 → S4 / S5）**

| 时间 | 动作 |
| --- | --- |
| 0 | 容器开始 spring.expand：宽、高、圆角同时插值，以顶边中心为锚点 |
| 0 | 旧内容 dur.fast 淡出，同时模糊 0→6、缩放 1→0.96 |
| 70 ms | 阴影不透明度 0→1，dur.base |
| 90 ms | 新内容入场：opacity 0→1，blur 12→0，translateY 8→0，scale 0.96→1；dur.slow，ease.out |
| 90 + 40·i ms | 子元素按阅读顺序错峰：图标 / 头像 → 标题 → 正文 → 按钮 |

**收起**

| 时间 | 动作 |
| --- | --- |
| 0 | 内容 dur.fast 淡出 + 模糊 0→8 |
| 40 ms | 容器 spring.collapse 回到目标尺寸，阴影同步 1→0 |
| 容器到位 | S1 / S0 的内容以 dur.base 淡入 |

铁律：内容永远比容器**晚到、早走**。

**出现与消失**

- Hidden → S4：transform-origin 取顶边中心，先 scale 0.7→1 + opacity 0→1，再接 spring.expand；允许额外 4% 过冲。
- 任意 → Hidden：先收为 S0 形态，再向顶边缩小 scale 1→0.6 并淡出，dur.base。

### 9.5 微动效清单

| 场景 | 动效 | 参数 |
| --- | --- | --- |
| 悬停 Peek | 整体放大，A 模式向下生长 | scale 1.05，origin 顶边中心，spring.peek |
| 岛按下 | 整体轻压，释放回弹 | scale 0.97，80 ms；释放 spring.press |
| 按钮按下 | 缩小，释放回弹 | scale 0.94，80 ms；释放 spring.press |
| 数字变化 | 垂直翻页滚动，仅变化位参与 | dur.base，ease.out，tnum |
| 徽标出现 | 由小到大 | scale 0→1，spring.press |
| 实时波形 | 3 条竖条上下律动 | scaleY 0.4↔1，周期 0.9 / 1.1 / 0.8 s，ease.inout，交替 |
| 录制红点 | 呼吸 | scale 1↔1.25，opacity 0.6↔1，1.2 s |
| 完成态 | 环形到 100% → 图标变勾 → 轻弹 | scale 1→1.15→1，spring.press，绿色，停留 1.2 s 后收起 |
| 内容更新（切歌、换会话） | 旧内容上滑淡出，新内容自下而上淡入 | translateY ±6，dur.base |
| 跟手拖动 | 1:1 跟手；超过 40% 距离或速度足够则触发，否则弹回 | 释放时继承速度，spring.morph |

**分裂 / 融合（S1 ↔ S1 + S2）**

### 9.6 AI 思考态（可选）

岛边缘 2 DIP 渐变光环：`conic-gradient(#BF5AF2, #0A84FF, #40C8E0, #FF375F, #BF5AF2)`，3 s 线性旋转一圈，外发光 blur 12、opacity 0.5。仅在 AI 处理中显示，同时最多 1 个；完成时光环 300 ms 收拢并淡出。这是本规范里唯一允许的渐变描边。

### 9.7 减弱动效

检测 Windows「动画效果」开关（UISettings.AnimationsEnabled）及应用内开关；关闭后：

- 所有弹簧换成 150 ms 线性淡入淡出，尺寸直接切换。
- 去掉过冲、模糊、缩放、阴影渐变。
- 波形、呼吸、AI 光环改为静态。
- 保留数字与颜色的变化（不带位移）。

### 9.8 弹簧引擎实现要点

- 弹簧用数值积分，不用预烘焙关键帧，才能做到「中途反向、继承速度」：

```
// 半隐式欧拉，m = 1；dt 取真实帧间隔，上限 1/30 s
function step(s, target, k, c, dt) {
  const a = -k * (s.x - target) - c * s.v;
  s.v += a * dt;
  s.x += s.v * dt;
  return Math.abs(s.v) < 0.01 && Math.abs(s.x - target) < 0.05; // 已静止
}
```

- 宽度用 spring.expand，高度刚度提高约 10%（k=210，c=23），形变会带一点「先宽后高」的有机感 ★。
- 任何输入（鼠标移出、新事件到达）都只修改 target，不重置当前 x 和 v。
- 全部弹簧静止后立即停止渲染循环（按需渲染），空闲时 CPU / GPU 占用应接近 0。

## 10. 交互与操作动线

### 10.1 状态转换表

| 当前 | 触发 | 目标 | 动画 |
| --- | --- | --- | --- |
| Hidden / S0 | 新事件（P2 及以上） | S4 | spring.expand |
| Hidden / S0 | 新的持续型事件（计时、媒体、下载） | S1 | spring.morph |
| S4 | 停留结束 | S1（有持续事件）或 S0 | spring.collapse |
| S4 | 点击主体 | 打开来源应用并收起 | spring.collapse |
| S4 | 点击回复入口 / 长按 | S5 | spring.expand |
| S1 | 悬停 ≥ 120 ms | Peek | spring.peek |
| S1 | 点击 | S5 | spring.expand |
| S1 | 出现第二个持续事件 | S1 + S2 | 分裂（§9.5） |
| S5 | 点击岛外 / Esc / 上滑 | S1 或 S0 | spring.collapse |
| 任意 | P0 事件到达 | S5（打断当前） | spring.expand；被打断的事件降为 S2 |
| 任意 | 用户横向滑走（忽略） | S0 | 向边缘滑出 + 淡出，dur.base |

### 10.2 输入与手势

| 输入 | 行为 |
| --- | --- |
| 悬停 | S0 / S1 进入 Peek；S4 / S5 暂停停留倒计时 |
| 单击 | 展开或执行主动作；点击卡片主体 = 打开来源 |
| 长按 350 ms | 展开到 S5，不跳转 |
| 右键 | 菜单：勿扰 30 分钟 / 1 小时 / 到明天、静音此应用、设置 |
| 横向拖动 / 触控板双指横滑 | 在 S1 / S2 / S6 之间切换事件；S4 向左右滑出 = 忽略 |
| 上滑 / Esc | 收起 |
| 滚轮 | S6 列表滚动 |
| 点击岛外 | 收起，点击穿透给下层窗口（不吞点击）；在 pointer-up 触发 |
| 全局快捷键（默认 Ctrl+Alt+Space，可配置） | 展开最近事件 / 把键盘焦点移到岛 |
| Tab / Shift+Tab / 方向键 / Enter / Space | 键盘遍历与触发 |

### 10.3 视觉与阅读动线

- 从左到右、从上到下：身份（图标 / 头像）→ 主信息（标题）→ 次信息（正文）→ 操作（按钮）。
- 每屏只有 1 个主操作，位于右下或右侧，使用语义填充色。
- 状态变化时视线锚点不动：展开始终以顶边中心为锚点生长。
- Compact 约定：左槽回答「是谁 / 是什么」，右槽回答「多少 / 还剩多久」。
- 展开态不超过 3 个信息层级：身份 → 主信息 → 操作。

### 10.4 事件调度与优先级

| 级别 | 示例 | 行为 |
| --- | --- | --- |
| P0 | 来电、严重错误、闹钟 | 立即打断，S5，常驻至处理 |
| P1 | 日历提醒、计时结束 | 打断 P2 / P3，S4 或 S5 |
| P2 | 消息、邮件、系统 HUD | 当前为 P0 / P1 时折叠为 S2 角标并排队 |
| P3 | 媒体、下载、同步 | 只以 S1 / S2 常驻，不主动展开 |

- 同时展开只允许 1 个；同时驻留的 S1 / S2 最多 2 个，更多进入 S6 托盘（先按优先级，再按时间倒序）。
- 节流：同一来源 10 s 内最多展开 1 次。
- 停留时长：文字类 = max(4 s, 字数 / 15 s)，上限 8 s；带按钮的 +2 s；悬停或键盘焦点时暂停，移开后再停 1.5 s 收起。
- 勿扰 / 全屏的处理见 §11。

### 10.5 反馈与容错

- 所有可点击元素 80 ms 内必须有视觉响应。
- 误触保护：收起手势需越过 8 DIP 位移阈值才识别；岛外点击在 pointer-up 触发而非 pointer-down。
- 撤销：忽略 / 清除操作后 4 s 内，在底行显示「撤销」胶囊。
- 失败不静默：操作失败时按钮水平抖动一次（translateX ±3，2 个来回，共 120 ms），并给出一句原因。

### 11.2 实现路径对照

| 路径 | 要点 |
| --- | --- |
| 原生（Win32 / WinUI + Composition） | 弹簧动画与自绘形体最容易做到 120 fps；透明、命中测试、DPI 控制最直接 |

## 13. 验收清单与落地

### 13.1 像素级验收

- ☐ 所有圆角为连续曲率，放大 800% 无「圆弧接直线」的突兀拐点。
- ☐ S0 → S4 → S0 全程无硬切；动画进行到一半反向，无跳变。
- ☐ 内容在容器到位前 90 ms 以上不可见（晚到），容器收起前已消失（早走）。
- ☐ 100% / 125% / 150% / 200% 缩放下边缘无发虚。
- ☐ 浅色、深色、纯黑壁纸下，岛的轮廓都清晰可辨（§6.2 自适应描边）。
- ☐ 计时、进度数字无抖动（tnum 生效）。
- ☐ 120 Hz 下掉帧率 < 1%；60 Hz 下无可见卡顿。
- ☐ 键盘可完成全部主流程；讲述人可播报事件。
- ☐ 全屏游戏、演示、专注助手期间不打扰（P0 除外）。
- ☐ 多显示器热插拔、更改缩放后位置正确。
- ☐ 点击岛外区域一律穿透，不吞点击。
- ☐ 开启「减弱动效」后无位移、模糊、缩放动画。

### 13.2 Do / Don't

| Do | Don't |
| --- | --- |
| 保持纯黑岛体，同时只用 1 个强调色 | 不用毛玻璃 / 亚克力，不用大面积彩色背景 |
| 一切形变用弹簧，动画可反向、继承速度 | 不做弹窗式淡入淡出，不硬切 |
| 内容晚到、早走 | 容器还没到位就显示内容 |
| 图标统一 1.75 线宽、圆角端点 | 混用多种图标风格、多色图标 |
| 只用 400 / 500 / 600 三档字重 | 用 700 以上或 300 以下字重 |
| 数字一律 tnum | 让计时数字左右跳动 |
| 默认不抢焦点，仅输入时例外 | 展开时偷走用户正在输入的窗口焦点 |
| 岛内信息不超过 3 个层级 | 在岛里塞满长文本与多个按钮 |

### 13.3 落地建议

- **Figma**：按 4 DIP 栅格建组件；圆角平滑设为 60%；用 Variables 对应 §12 的 token；动效用 Smart Animate + 自定义 spring 预览 §9。
- **实现顺序**：第 1 阶段做 S0 / S1 / S4 三态 + 独立的弹簧引擎（k、c 可热调）；第 2 阶段做事件模板、队列与优先级；第 3 阶段做平台适配（DPI、多屏、全屏检测）与无障碍。
- **校准流程**：所有 ★ 项用实机录屏逐帧对比 Apple 原版参考，以 1 DIP / 1 帧为精度调整，调完把最终值回写 §2.2、§9.2、§11.1。
- **版本维护**：任何 token 变动同步更新 §12；动效与尺寸变动需附录屏对比。
